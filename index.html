    How it works

    Repos. Only established repos are tracked: every repo here has 5k+ stars. They come from the curated lists below, GitHub topics, and GitHub Trending (repos and developers' popular repos). Every day around 00:00 KST (runs may be delayed a few hours) a GitHub Action records each repo's star count and ranks them by growth over the last 7 days. When less than a week of history exists, the oldest available snapshot is used — the window is shown next to each number. Data is plain JSON in the repo.

    Skills. Every skill on the skills.sh all-time and trending leaderboards (about 13k) is read once a day from the public data skills.sh's own leaderboard uses. Install gains compare each day's all-time install counts, the same way stars are compared. Trending means the top 300 of skills.sh's 24-hour list: a skill enters or leaves it on the first day it crosses that line. Install counts are skills.sh's CLI telemetry.
